# leomatch

Telegram-юзербот для Дайвинчика. При взаимном лайке автоматически пишет опенер и ведёт диалог — через локальный Ollama, от твоего лица.

**Что умеет:**
- Отслеживает уведомления от `@leomatchbot` о взаимных лайках
- Генерирует персонализированный опенер через Ollama
- Продолжает переписку: понимает контекст, отвечает в твоём стиле
- Отвечает только тем, кому сам написал (не лезет в другие чаты)
- Случайная задержка перед каждым сообщением (анти-бан)

---

## Быстрая установка

```bash
git clone https://github.com/vovafes/leomatch.git
cd leomatch
bash setup.sh
```

Скрипт сам создаст окружение, установит зависимости и попросит `API_ID` / `API_HASH`.

---

## Настройка личности

Открой **`persona.yml`** — это единственный файл, который нужно редактировать:

```yaml
name: "Артём"
age: 24
about: >
  Работаю UX-дизайнером, гоняю на велике, хожу на концерты.
character: >
  Ироничный, спокойный, не душнила.
writing_style: >
  С маленькой буквы, без смайлов, короткие фразы.
taboo: >
  Никакого «Привет, как дела?», пошлости, пикап-техник.
```

После изменений — просто перезапусти бота.

## Запуск

```bash
# 1. Запусти Ollama (если ещё не запущена)
ollama serve
ollama pull llama3       # или mistral, gemma3 — на твой выбор

# 2. Активируй окружение и запусти бота
source .venv/bin/activate
python main.py
```

При первом запуске Pyrogram попросит номер телефона и код из Telegram — это одноразово. Сессия сохраняется в `leomatch_session.session`.

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `API_ID` | — | С [my.telegram.org](https://my.telegram.org) |
| `API_HASH` | — | С [my.telegram.org](https://my.telegram.org) |
| `OLLAMA_URL` | `http://localhost:11434` | Адрес Ollama |
| `OLLAMA_MODEL` | `llama3` | Модель (`mistral`, `gemma3`, ...) |
| `REPLY_DELAY_MIN` | `15` | Мин. задержка перед ответом (сек) |
| `REPLY_DELAY_MAX` | `90` | Макс. задержка перед ответом (сек) |

## Как работает

```
@leomatchbot → уведомление о взаимном лайке
    └─► парсинг username и имени девушки
    └─► Ollama генерирует опенер (persona.yml как личность)
    └─► задержка 5–15 сек → отправка опенера
    └─► девушка записывается в data/contacts.json

Девушка отвечает в ЛС
    └─► бот проверяет: есть ли она в contacts.json?
    └─► да → Ollama генерирует ответ с учётом всей истории
    └─► задержка REPLY_DELAY_MIN–MAX сек → отправка
    └─► история обновляется в contacts.json
```
