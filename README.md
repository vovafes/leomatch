# LeoMatch

Telegram-юзербот для Дайвинчика. При взаимном лайке автоматически пишет опенер и ведёт диалог — через Groq AI (бесплатно), от твоего лица.

**Что умеет:**
- Отслеживает `@leomatchbot` и пишет опенер при взаимном лайке
- Ведёт полноценный диалог с учётом истории переписки
- Отвечает только тем, кому сам написал
- Ставит чат на паузу, если написал сам вручную
- Симулирует "печатает..." перед отправкой
- Фильтрует спам и подозрительные сообщения
- Web-дашборд с управлением на лету

---

## Быстрая установка

```bash
git clone https://github.com/vovafes/leomatch.git
cd leomatch
bash setup.sh
```

Скрипт создаст окружение, установит зависимости и спросит API-ключи.

## Дашборд

### Чаты
Список всех переписок с Дайвинчика. Можно открыть чат, посмотреть историю, поставить на паузу или возобновить.

### Активность
График отправленных и полученных сообщений за 14 дней.

### Настройки
| Секция | Что настраивается |
|---|---|
| **Биография** | Имя, возраст, стиль общения — без перезапуска |
| **Задержки** | Мин/макс пауза перед ответом, лимит в час |
| **Расписание сна** | Часы, когда бот не отвечает |
| **Стикеры** | File ID стикеров + вероятность отправки |

---

## Режимы работы

Переключаются в хедере дашборда:

| Режим | Что делает |
|---|---|
| **AUTO** | Бот пишет сам |
| **HYBRID** | Генерирует ответ, но не отправляет (видно в логах) |
| **OFF** | Бот молчит |

---

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `MODE` | `AUTO` | Режим работы |
| `REPLY_DELAY_MIN` | `15` | Мин. задержка (сек) |
| `REPLY_DELAY_MAX` | `90` | Макс. задержка (сек) |
| `SILENCE_TIMEOUT_MINUTES` | `60` | Не используется (удалён nudge) |
| `MAX_MESSAGES_PER_HOUR` | `10` | Лимит сообщений в час |
| `WEB_ENABLED` | `true` | Дашборд |
| `WEB_PORT` | `8082` | Порт дашборда |

