# LeoMatch

Telegram-юзербот для Дайвинчика. При взаимном лайке автоматически пишет опенер и ведёт диалог — через Groq AI (бесплатно), от твоего лица.

**Что умеет:**
- Отслеживает уведомления от `@leomatchbot` и пишет опенер
- Ведёт полноценный диалог с учётом истории переписки
- Отвечает только тем, кому сам написал (в чужие чаты не лезет)
- Ставит чат на паузу, если написал сам вручную
- Симулирует индикатор "печатает..." перед отправкой
- Пишет nudge, если девушка давно молчит
- Фильтрует спам и подозрительные сообщения
- Web-дашборд с переключением режимов на лету

---

## Быстрая установка

```bash
git clone https://github.com/vovafes/leomatch.git
cd leomatch
bash setup.sh
```

Скрипт сам создаст окружение, установит зависимости и спросит API-ключи.

## Настройка личности

Открой **`persona.yml`** — это единственный файл для редактирования:

```yaml
name: "Артём"
age: 24
about: >
  Работаю UX-дизайнером, гоняю на велике.
character: >
  Ироничный, спокойный, не душнила.
writing_style: >
  С маленькой буквы, без смайлов, короткие фразы.
taboo: >
  Никакого «Привет, как дела?», пошлости, пикап-техник.
```

После изменений — просто перезапусти бота.

## Режимы работы

Переключаются прямо в дашборде или через `.env`:

| Режим | Что делает |
|---|---|
| **AUTO** | Бот пишет сам |
| **HYBRID** | Генерирует ответ, но не отправляет (видно в логах) |
| **OFF** | Бот молчит |

---

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `MODE` | `AUTO` | Режим работы |
| `REPLY_DELAY_MIN` | `15` | Мин. задержка перед ответом (сек) |
| `REPLY_DELAY_MAX` | `90` | Макс. задержка перед ответом (сек) |
| `SILENCE_TIMEOUT_MINUTES` | `60` | Через сколько минут тишины слать nudge |
| `MAX_MESSAGES_PER_HOUR` | `10` | Лимит сообщений в час на чат |
| `WEB_ENABLED` | `true` | Включить дашборд |
| `WEB_PORT` | `8082` | Порт дашборда |

## Как работает

```
@leomatchbot → взаимный лайк
    └─► парсинг @username + имени
    └─► Groq генерирует опенер (persona.yml как личность)
    └─► задержка 5–15 сек → отправка
    └─► запись в data/bot.db (SQLite)

Девушка отвечает:
    └─► проверка: есть ли в нашей БД?
    └─► фильтр спама и подозрительных сообщений
    └─► Groq генерирует ответ с полным контекстом
    └─► typing indicator → задержка → отправка
    └─► история обновляется в БД

Ручная отправка тебя:
    └─► бот замечает → ставит чат на паузу автоматически

Долгое молчание (60 мин):
    └─► Groq генерирует nudge → отправка
```

## Структура

```
leomatch/
├── main.py              # точка входа, все хэндлеры
├── config.py            # настройки из .env
├── persona.yml          # ← редактируй под себя
├── setup.sh             # одноразовая установка
├── ai/generator.py      # Groq/OpenAI API + system prompt
├── db/models.py         # SQLite: чаты, сообщения, настройки
├── utils/delays.py      # задержки, typing, rate limit, спам
├── web/server.py        # aiohttp API
├── web/dashboard.html   # дашборд
└── data/bot.db          # история (авто, не в git)
```
